1 · 新增订阅方（订阅校验）

回调地址可用内置模拟端 /mock/subscribers/<id>/callback。创建即发起 WebSub 风格校验，secret 仅显示一次。

2 · 生成通知（5 类事件 → 不可变信封）

发布 / 撤销 / 开始 / 结束 / 报告订正。每个事件一个全局顺序信封，按订阅方分别持久入队。

3 · 故障注入 / 密钥轮换

先选中右侧订阅方，再注入。模拟投递端暂时失败、确认丢失、重复确认、订阅校验拒绝。
